# NeuroGraph 研究展示

疼痛 fMRI 项目的研究进度、聚合指标、方法说明与公开报告。

访问网站：[NeuroGraph](https://onephantomcat.github.io/neurograph-site/)。

这是只读网站。数据按各报告及快照日期解释，页面刷新不会启动训练或重新检查远端处理状态。内部开发、站点留出和独立验证分别报告，阴性结果及方法限制保留。

本版本提供 1,958 份公开来源文件。78 份公开副本省略了个体编号或本机路径；原研究文件未改写。逐人数据、模型、原始影像、QC 图与审核库保留在研究工作区。38 份本机材料保留目录说明，不提供公开下载。

更新时重新导出只读网站，将生成的页面、聚合材料与快照提交到本仓库。不要把研究工作区或私有项目仓库整体复制到这里。
