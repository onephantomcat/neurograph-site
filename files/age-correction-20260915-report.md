# 训练侧年龄校正与年龄外推评估（2026-09-15）

**已完成两个限定候选、120个最终校正模型和独立核验。本轮未获得稳定的双向迁移改善，保留原切空间为内部开发参考。**

年龄校正在OSU→CIN上AUC从0.6078提高到0.6353，但灵敏度从51.76%降到35.29%，BA基本不变；CIN→OSU的AUC由0.6129降到0.5267，特异度由26.32%降到15.79%。内部99/96人结果也下降。加入头动/删帧未形成一致收益。不能仅以一个方向的AUC或准确率上升认定成功。

## 限定实验方法

- **主候选：训练对照年龄校正。** 每个内层/外层训练集独立拟合切空间参考；仅在该训练集健康对照上拟合每条连接对年龄的线性关系。年龄按训练对照均值/标准差标准化，OLS含截距。对所有训练人与测试人减去年龄斜率贡献，保留截距，再拟合训练侧StandardScaler与balanced Logistic。
- **敏感性候选：年龄＋平均FD＋删帧比例。** 用相同方法在训练对照上同时拟合三个变量；与年龄单变量结果分别报告。未把站点/协议或测试标签加入校正器。
- **固定比较条件。** 原99/96人、5重复×5外折×3内折、C={0.001,0.01,0.1,1}和阈值0.5。两个站点留出方向各用原5种来源内层种子。旧原切空间60个概率分支重新回读，无新增分类器/阈值搜索。
- 训练对照拟合的线性关联不是纯年龄生理效应；混合站点的年龄与站点仍相关。使用训练对照不能保证保护所有疾病信号，也不等于扫描协议已被校正。

方法式：训练对照上拟合 X = 截距 + Z标准化 × B；应用 X校正 = X − Z标准化 × B。Z的均值、标准差与B均只来自当前训练对照。切空间参考来自当前全部训练人，不能在内层前预先用外层全体拟合。训练内变换原则见[scikit-learn文档](https://scikit-learn.org/0.24/common_pitfalls.html)。

## 独立核验

- 120个最终校正模型、60个训练侧切空间参考和60个原模型概率分支均核对。独立协方差特征分解与系数重算最大概率差1.57e-14；训练对照OLS用独立伪逆重算，系数最大差8.23e-14。
- 参考矩阵差0，原预测差0；总体及年龄分组指标最大差2.22e-16。
- 全部身份、内外折、训练对照身份、OOF选参算术、训练均值/方差和年龄分组检查。第一重复额外重训72个已选内层模型，最大概率差1.74e-14；其他内层候选不全部重训。
- 外层校正拟合对照数范围19—43；全部设计矩阵满秩，标准化后最大条件数4.275。矩阵可求解不等于临床有效。
- 共1440次内层候选拟合、120个新最终疾病模型；参考模型为复用回读。无新增受试者、无放宽QC、无更改原标签/影像/模型/依赖或远端队列。

## 当前判断与后续

1. 原切空间继续保留为内部开发参考；本轮两个线性校正候选不替换它。单方向AUC小幅上升伴随灵敏度损失，反方向和内部表现下降。
2. 年龄差异和强站点可识别性是事实，但线性年龄剔除未解决问题，不能据此推断年龄没有影响，亦不能宣称已找到唯一原因。继续增加相同校正参数没有本轮证据支持。
3. 下一项有意义的工作是补齐协议13/14原始参数表，核对疾病组成和年龄共同支持；再决定是否存在可执行的来源匹配或站点校正设计。对于完全共线的站点与协议，当前两中心数据无法独立估计两者作用。
4. TN/PHN评分时间对应、病程、用药及新中心仍需相应外部材料；本轮未检查邮件，不能判断作者是否回复。本轮只交付本地报告及证据，未Git推送或更新网站。
