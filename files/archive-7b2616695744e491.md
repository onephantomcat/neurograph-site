# Native SRPBS1600 clinical transfer smoke

The native AAL90 adapter is `src/oa_rebuild/srpbs_clinical_transfer.py`; the entrypoint is `scripts/run_srpbs_clinical_smoke.py`.

It reuses the existing `external_transfer` FC autoencoder, standardizer, reconstruction trainer and classifier. It does not change the old AAL116-source loader or identify the clinical target as OA. Native input packages must have exact subject and atlas order, real upstream arrays, numerical PASS and user approval for the matching attempt. All 145 clinical IDs are excluded from the source, not just currently available targets.

The 2026-09-04 real-data run used 9 sources and 20 clinical targets (11 Healthy/9 Pain), with one epoch per reconstruction stage and two outer/two inner folds. Four methods produced 80 complete out-of-fold predictions; fit/test overlap was zero and checkpoint reload was exact. This proves execution only: `REAL_DATA_SMOKE_ONLY`, not comparative efficacy, independent validation or a formal study protocol.

