## 常见缩写

- **SSH**：连接实验室服务器的通道；查看网页无需手动输入服务器命令。
- **QC / 质控**：检查数据质量。程序检查通过后，影像仍需研究者看图确认。
- **T1 / BOLD / fMRI**：T1主要看脑结构；BOLD是功能磁共振采集的信号，用于研究脑活动变化。
- **AAL90 / FC**：AAL90把脑划分为90个区域；FC记录不同脑区信号变化之间的联系。
- **TN / PTN / PHN / ZAN**：分别指三叉神经痛、原发性三叉神经痛、带状疱疹后神经痛、带状疱疹相关神经痛；ZAN不能直接全算成PHN。
- **NRS / VAS**：两类疼痛评分。范围、提问内容和填写时间需要核实，不能直接混用。
- **预训练 / 迁移**：先用已有数据学习，再检查学到的内容能否帮助目标任务。
- **训练 / 验证 / 测试**：训练用于学习，验证用于挑选方案，最终测试用于检查选定方案；同一人不能跨组。
- **AUC / MAE**：AUC衡量分类区分能力；MAE表示预测分数与实际分数平均相差多少，通常越小越好。
- **OOF / 站点**：OOF是每个人未用于该次训练时得到的预测；站点指采集数据的医院或中心。
