# CortexMAE支持内有效秩与站点/协变量诊断

2026-10-19，计算前方案。用户要求先完成诊断，再决定下一实验；音乐仍等原QC。本轮不训练预测器，不重新编码，不读取MRI。

复用原99人、50个K10/20支持所形成的100个支持内分区，每个内训练分别10或20人。只使用各内训练人的768维冻结表示；内留出和原外查询不进入PCA、尺度、混杂投影或选择。官方预训练及固定随机编码器两个既有缓存同人比较，四协变量和站点按原人员键逐项对齐。年龄、原sex code2指示、mean FD和删帧比例的含义不互换。

每分区检查原始中心化表示与原头所用的训练侧逐维标准化表示。使用协方差特征值计算熵有效秩exp(H)、参与率、PC1及前3/5/8累计方差、80/90/95%方差所需维度。报告秩上界n−1与有效秩/上界，不能把10/20人的代数低秩当成有用低维结构。

在标准化表示中，使用中心化站点one-hot、四协变量、两者联合及诊断标签的正交投影，计算其描述性解释方差；列设计实际秩、自由度、调整R²。进一步计算站点在协变量之外、诊断在站点/协变量之外的独有方差增量。这是训练内描述性关联，不是新监督预测器、不是混杂的因果归因，也不估计外部泛化。

每内训练分区固定199次人员行置换，SeedSequence([20261019,k,outer,repeat,inner])，对两编码器共用。保留设计内部关系与秩；比较原解释方差和置换中位数/95%分位。小n高自由度会产生较大偶然解释方差，不能只报原R²。分区重叠，100个分区不是100队列，不将重复结果合并为独立显著性。

只检查事先提出的固定PCA8：训练内保留总方差比例，以及保留部分的站点、联合协变量、诊断关联；不扫维度选最高分。若仅代数低秩、保留方差随预算变化，或无法证明保留了可泛化疼痛信息，则不因压缩即可训练而启动PCA8头。是否值得后续模型比较根据诊断提出一个具体问题，不能用外查询挑维度/权重。

保存200行编码器/分区聚合诊断、PC统计和分预算汇总。个人键、特征、逐人站点/标签及投影基留私有；公开聚合指标、限制和真实未完成项。既有阴性结果/停止分支、QC及音乐运行均不改。
