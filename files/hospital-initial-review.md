# 医院需求研究侧初审：原发性三叉神经痛优先

2026-09-09 09:20更新。用户补充院方反馈：神经病理性疼痛患者较多，包括带状疱疹相关神经痛和三叉神经痛。这是已有的病种来源线索；各病种月病例量、可招募人数、MRI厂商/型号/场强和科研时段仍未知。

**初审结论：研究侧首选原发性三叉神经痛（PTN），带状疱疹后神经痛（PHN）作为备选独立队列。** 院方反馈替代此前缺乏病例信息时的腰痛建议。完成的是研究侧方案初审，尚无医院正式审核、设备适配或采集批准；不将两个病种合并成主要分析的“神经痛”。

## 1. 首选病种与研究问题

首个主要任务是**PTN患者内疼痛强度连续预测**，从脑静息态功能连接预测扫描前一周的发作疼痛负担，检验相对于简单模型的增量价值。属于横断面研究，不是未来预后或临床诊断工具，也不把预测值称为客观疼痛真值。

选择PTN的理由：院方报告这类病例较多，且DS005713原始研究同为原发性三叉神经痛，能形成“疾病相关来源→新医院同病种”的设计。来源包仅36扫描/33人、完整诊断连接仍不足，当前迁移增益也未确立，因此这些理由支持优先核查可行性，不能证明PTN样本足够或模型有效。

拟议研究人群（疼痛科/神经科逐条确认）：

- 成人≥18岁，由临床按ICHD-3确认三叉神经痛；原发性在本方案指经典型或特发性，必须分别记录，不能只填写“面痛/神经痛”。ICHD-3区分经典、特发及继发类型，诊断基于临床，影像用于病因判断。[ICHD-3](https://ichd-3.org/13-painful-cranial-neuropathies-and-other-facial-pains/13-1-trigeminal-neuralgia/)
- 首轮选择当前治疗决策前/本轮介入或手术前的基线访视；保留既有药物治疗并记录剂量和最近服药时间，不为研究停药。既往手术、射频等破坏性介入后的患者首轮单列，不混入主要基线队列。
- 记录患侧、V1/V2/V3分支、病程、诱发因素、每日发作次数、单次时长以及是否伴持续背景痛。纯阵发型与伴持续痛者分别描述和作预设敏感性分析；不靠“扫描当时不痛”排除患者。
- 多发性硬化、肿瘤等继发性TN，以及带状疱疹相关三叉神经病、牙源性/其他面痛单列，不并入PTN主分析；不要把“血管接触”自动判定为经典型的致病压迫。
- 医院按常规完成MRI适宜性筛查；量表能力、影像可用性、量表缺失分别记录。研究人员不凭脑FC判断专科诊断，不以推测的病因补标签。

**PHN备选定义**：先请医院区分急性带状疱疹痛与持续神经痛。拟采用同一原皮疹区域疼痛持续到皮疹出现后>90天的操作定义；记录出疹日期、疼痛起始、部位/皮节及残留皮损。用户说“带状疱疹神经痛”尚不能自动认定全部满足PHN。[CDC定义](https://www.cdc.gov/shingles/hcp/clinical-signs/index.html)

PHN可在PTN病例流量不足时改为首个单病种，但需要在采集和主要模型选择前另写PHN方案与结局口径；或后续作为独立跨疾病扩展。现有公开来源没有经确认的PHN专门预训练/测试包。不能把PHN当PTN的健康对照，也不能把混合Pain全改成PHN。

健康对照用于次要PTN/健康分类及影像混杂分析，尽量平衡年龄、性别、设备和用药背景；不进入患者内主要回归充当人为零分样本。病种特异性问题需另行与其他疼痛队列比较。

## 2. 主要结局：适应阵发性疼痛的七日日记

| 项目 | 本次确定的研究侧方案 |
| --- | --- |
| 主要结局 | **扫描前连续7个完整日，每日最严重三叉神经痛NRS（0–10）的均值**；是近期发作强度指标，不称为全部疼痛负担或临床金标准 |
| 日记用语 | 每日固定晚间记录“今天最严重的一次三叉神经痛有多痛”；0=无痛，10=能想象的最严重疼痛。确实无发作且无相关疼痛可记0，并另记“当日无发作” |
| 有效性与时点 | 至少5/7有效日方计算主要结局，同时报告有效日数；7/7完整者作敏感性分析。这是拟议操作规则，待临床确认。漏填不补0，回忆补填需标记；扫描日即时痛另记 |
| 主要任务/指标 | PTN患者内MRI/FC回归；最终测试MAE，单位NRS分，受试者层面95%区间 |
| 次要指标 | RMSE、R²、Spearman及预测校准；不能用相关显著替代低预测误差 |
| 必须伴随记录 | 同七日每日发作次数/估计方式、发作时长、持续背景痛强度、患侧与分支、药物剂量/时点及治疗变更；频次不是主要目标的模型输入 |
| 次要临床结局 | BOLD前后即时NRS、日记发作频次、疼痛对进食/说话/睡眠的影响；BNI可按医院现行版本单列，但不直接换算NRS或用作同一目标输入 |
| 次要研究 | PTN与健康对照分类，报告ROC-AUC/AP/Brier；不把分类好坏作为连续结局预测成功的替代 |

0–10 NRS量尺参考IMMPACT建议；“七日日最严重均值”及5/7规则是针对TN阵发性的本研究建议，尚未经本项目验证，并非TN专门共识终点。[IMMPACT](https://www.immpact.org/static/meetings/Immpact4/IMMPACT-4_article.pdf)

选择理由：一次扫描前即时评分可能恰处无痛间歇，单日均痛也可能掩盖短时重度发作。七日记录减少依赖一个时点，但仍可能出现高分集中、发作频次差异和药物混杂。须先检查日记完成率和目标分布；若不足以支持回归，先在开发阶段修订研究问题，不能看完最终测试后换终点。不存在“必须停药以产生疼痛”的要求；不在静息扫描中诱发发作。

病历目标分数、同义量表、诊断后推导分值或发作日记内容不输入预测同一结局的模型。缺失不补0，对照不人为赋0；不同量表/时期不自动统一。DS005713电话随访NRS及SRPBS VAS都不能直接当作本研究七日NRS标签。

保留训练集均值、年龄/性别/头动等混杂模型、Raw FC正则化回归、固定来源及训练部分适配比较。插补、标准化、特征选择、谐调与调参均限训练部分。临床可接受MAE及样本量待标签分布和测试精度论证，不把治疗改善MCID当模型误差阈值。

## 3. MRI建议协议：医院适配前的具体起点

拟采用**3T脑MRI：全脑3D T1 + 静息态BOLD + 畸变校正辅助序列**。优先与现有SRPBS分析衔接，以ATR公开统一协议为参数起点；该协议是2014年的多中心研究参考，并非疼痛专病标准，也不代表医院扫描仪已有相同序列。[ATR官方协议PDF](https://bicr.atr.jp/wp-content/uploads/2018/08/UnifiedProtocol-1-1.pdf)

| 模块 | 建议设置 | 适配/记录要求 |
| --- | --- | --- |
| 设备 | 3T，固定设备与头线圈 | 厂商、型号、线圈通道、软件版本、院区和序列版本均待影像科提供 |
| T1 | 3D T1加权，全脑1 mm各向同性 | 厂商等效序列；TR/TE/TI/翻转角按设备优化并回填，不编造统一值；完整脑覆盖 |
| BOLD | T2* EPI；TR=2.5 s，TE≈30 ms，翻转角≈80° | 作为兼容性起点；若设备需变更，记录实际值并先验证转换及预处理 |
| 空间 | FOV约212 mm，矩阵64×64；层厚3.2 mm、层间距0.8 mm，约40层，轴向升序 | 面内实际分辨率3.3125 mm；以完整全脑覆盖优先，不为照抄40层牺牲脑区；保存真实SliceTiming |
| 时间 | 240个可用体积，另有4个起始稳定体积；约10分10秒 | 必须明确设备已自动丢弃还是导出244体积；只丢弃一次。旧107例240体积/dummy=0记录不改为丢4 |
| 编码与加速 | 起始参考PA、单带；具体加速参数记录 | BIDS方向按转换后的轴映射填写，不能仅写PA就推断为j/j-；保存读出时间 |
| 畸变校正 | 优先可用的B0相位+幅度场图；或与流程匹配的反向相位编码参考 | 由影像科和处理人员选一种可运行方案，记录TE差/读出时间等；预计额外约2分钟，实际待测。现有流水线不能据此声称已执行校正 |
| 静息条件 | 睁眼注视固定点、保持清醒，固定头部；扫描前后询问疼痛/困倦 | 避免头部固定装置压迫已知面部触发区，记录扫描中的自发发作与头动；勿自行停药、镇静或施加疼痛刺激 |
| 导出 | 脱敏DICOM或NIfTI+参数JSON、匿名受试者/访视表、量表字典 | 保留方向、单位、TR/TE、层序、相位编码、体积和时点；医院保管身份映射 |

临床诊断影像需与研究FC区分：由神经科/影像科核对是否已有适用于TN病因分型的检查。必要时按院方临床流程补充高分辨率三叉神经/脑池序列等；本研究1mm T1与BOLD不替代经典型/继发病因判定。具体专科序列和额外时长待设备与临床需要决定，不默认已采集。

MRI预约暂按约20–25分钟的研究估算讨论（含定位/T1/BOLD/辅助序列，是否含入室准备由院方定）；当前没有设备计时证据。全脑覆盖、舒适度与有效时间不能只靠参数表判断，须实际样例测量。相同场强和AAL90并不自动消除站点或GSR等预处理差异。

## 4. 数据集分工及验证

完整疾病和人数见[数据集角色表](DATASET_ROLES_AND_DISEASES_2026-09-09.md)。主要方案：ABIDE提供一般脑连接表征，DS005713提供疼痛相关来源对照，SRPBS非临床来源用于域适配对照；三者不承担新的PTN临床确证。

医院拟分H-dev与H-test，均为PTN患者：H-dev负责监督训练、内部验证及调参；H-test只做最终评估。同一人全部访视必须归同一角色。具体比例与例数在病例量和所需精度明确后确定，当前不凭经验写一个“够用”的总人数。H-dev内用按人分组的交叉验证，小样本时减少折数并如实报告不确定性。

同医院后续独立患者组成的H-test只能称时间外验证；另一独立医院、且未用于适配/选模型的队列才能支持未见医院验证。若外院数据参与微调，另留未接触的测试患者。医院尚无数据，所有医院角色目前是计划，不是已划分或已完成。
