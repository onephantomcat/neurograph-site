# 偏头痛真实输入试验：头动、空间处理与官方模型运行

2026-10-02。接续[全库元数据与真实文件核查](migraine-readiness-20261002.md)。以下是两人技术试验，未做分类训练，也未新增 QC 纳入；不从两人结果估计全队列质量或诊断效果。

## 已完成的头动测量

两人的 300 帧原生静息态影像分别完成 SPM/DPABI 运动校正，各得到 300×6 运动参数。采用 Power FD、旋转半径 50 mm、首帧 FD=0，独立复算与 DPABI 保存值的最大绝对误差低于 1.2×10⁻¹⁶ mm。

聚合检查：两人平均 FD 范围 0.1470–0.2048 mm，最大帧 FD 范围 0.4794–0.8420 mm；FD>0.5 mm 帧数范围 0–2/300；将超阈值帧向前扩 1 帧、向后扩 2 帧后，涉及 0–5/300 帧。此处测量覆盖完整 300 帧，没有宣称已按最终训练处理规则删帧。运动校正均值图的技术查看已完成，不能替代逐例专家审核。

## 空间处理的实际进展

两人已完成原生 T1 分割、T1–EPI 刚性配准及旧分割参数的标准空间归一化。检查原生 T1 配准前后体素不变，刚性变换只修改坐标；EPI 转回原生分割坐标后再用保存的非线性参数归一化。没有直接把原生 40 层影像当 MNI 输入。

实际输出为 91×109×91×300，空间 2 mm、TR 2 秒、LAS。脑掩膜有限且与功能像坐标一致，脑内全部时间点有限。脑外固定 NaN 体素范围为 54,635–93,461，全部不在脑掩膜内，不随时间变化；原始标准化结果保留 NaN，不覆盖成全有限数据。两人的标准空间第150帧及脑掩膜三方向共6个技术面板已实际查看，不能替代专家配准审核。96³候选格沿Y轴取[6,102)，X/Z轴各补前2后3层，两人均保留100%已有脑掩膜体素；它是本地补边规则，作者中央裁框函数本身不会把小于96的维度补齐。模型输入仍需单独生成并记录脑外背景与时间重采样规则，没有新增QC纳入。

## 官方 288 维模型：加载成功，前向尚未完成

使用作者源码版本 `d43114c97deaf3e53ea051d2512b36ef8fcb748d` 与官方五数据集预训练 checkpoint，文件大小及官方既有 LFS 内容标识一致。按 checkpoint 中的真实配置构建编码器：起始通道 36，深度 [2,2,6,2]，四阶段最后 288 通道；原始 Mamba 使用 d_state=16、d_conv=4、expand=2。

223 个编码器状态张量严格加载成功，缺失和意外编码器键均为 0；编码器实际参数 5,173,020。186 个仅用于预训练掩膜/解码的张量显式排除。冻结 eval 模式及固定随机种子 20261004 已核查；同结构随机初始化可逐张量重放一致。该编码器没有注册的固定 buffer，学习的位置/时间参数不与预训练分支共享。

服务器独立环境使用 Python 3.10、Torch 2.4.1+cu121、MONAI 1.3.2，与作者 Torch 2.7.1 环境有差异，需报告运行环境适配。小型原始 Mamba 实际 CUDA 前向失败：现成扩展未包含 GTX 1080 Ti 所需的 sm_61，报 `no kernel image is available for execution on the device`。权重加载成功不等于模型前向成功。

独立 CUDA 12.1 编译器已运行，正在从指定版本的作者原始 Mamba/causal-conv1d 源码编译 sm_61；只改编译目标，不改公式、内核或模型结构，也不更换为旧 E192 或替代后端。全局驱动、工具链和共享科学环境不改。必须通过真实小 Mamba、完整 96³×20 编码器和实际影像输入后，才记录表示提取成功。当前官方完整编码器前向 0、真实人员表示 0、分类拟合 0。

## 已修复的技术问题与剩余边界

试验中修复了工作目录缺少父目录、MATLAB SubjectID 需要 cell 而非字符数组、配准的起始目录尚无输入，以及重写均值图时继承整数编码造成的量化。失败日志与原配置保留；均值图从未改写的运动校正源重新读取，输出为 float64，并逐体素复核。已完成的分割、配准和标准化没有为重试而全部重跑。

尚未完成模型的时间重采样与窗口汇总、官方 CUDA 前向、AAL90 覆盖/去噪及全队列处理。设备混杂、年龄/同期疼痛/治疗结局缺失、跨数据身份和预训练重叠未知等限制保持。原20不评分、TN14停止、结构535停止及其他暂停队列不变。实际训练前的有限比较见[运行前设计](migraine-readiness-20261002-protocol.md)；正式文献和区间口径见[比较报告](migraine-input-pilot-20261002-literature.md)。
