# AAL90网络对双线性编码：拟合前方案

2026-10-27。问题：在原79人诊断开发池中，保留网络对之间完整有符号FC的轻量编码，是否比同容量乱序分组和既有切空间线性FC有稳定增量？本轮是NERVE结构启发的本地监督适配，不是官方NERVE复现，也未验证疼痛分级或临床泛化。

只使用既有fc-spd-matched-20261026/run/features_private.npz的79×90×90 FC、原标签和identity中的三个内折。37病例/42对照；训练52/53人，验证26/27人。float32输入与原BrainHGT一致；SPD/切空间线性参照原float64结果保持。对称、负边、对角线1和原AAL90次序不变。无新的数据拟合、归一化、协变量、时序输入或图重建。

读取原BrainHGT的dice_prior.csv，按每行argmax固定分为Yeo1–7和未覆盖组；Other仅为原映射的未覆盖组，不是第八个功能网络。真实分组与一次固定种子20261027的组大小保持置换配对。固定置换跨全部内折/训练种子共用，不按标签或成绩选择。

对所有a≤b共36个含自配对，8维token为 sum_ij FC_ij P_ik P_jk，i属于a、j属于b。P为90×8、同一ROI在各网络对共用。288维直接接二分类线性头。1298可训练参数；无Transformer、额外注意力、池化、MAE、预训练或辅助损失。P以randn/sqrt(90/8)初始化，无训练拟合的尺度。每个内折/seed的两条件P和头初值完全相同，仅membership不同；预生成的每轮训练人排列也完全相同。

两条件×原三个内折×seed0–4，最多30新模型。CPU两线程、GPU0；普通CE，Adam lr=1e-4、weight_decay=1e-4，batch32、100轮、每轮两次更新，200次更新/模型、100次验证选轮机会。按最高验证AUC选轮，精确相同取最早。总上限6000更新、3000验证机会，运行时间上限3600秒；不扩展配置、不自动重拟合失败作业。复用原15 BrainHGT、15匹配影像SPD、3确定性切空间线性FC预测，参照重拟合0。

主要比较同时为真实分组减乱序、真实分组减切空间线性FC；SPD和BrainHGT为辅助比较。各seed先均三个内折，再报告五seed均值/样本SD及全部种子。复用既有2000次折内、分标签人级配对抽样，报告ΔAUC/Brier/logloss条件95%区间；该区间不包含重训练、选轮和累计开发偏差。只有两个主要比较均满足平均ΔAUC>0、至少4/5正向seed、平均Brier/logloss不恶化且ΔAUC条件95%下界>0，才支持后续开发候选；不通过则停止此固定配置，不追加调参。

保存初始/选轮/末轮权重、全部训练/验证概率及logit、曲线、每批训练人员与损失、人员映射、逐模型元数据、技术失败和阴性。严格Torch回放选轮及末轮要求概率最大差0；独立NumPy分块循环回放最大logit差<2e-5、概率差<2e-6；独立sklearn复算主要指标最大差<1e-6（float32存储运算差）；全部人员/更新/选轮核对。先用纯合成有符号对称矩阵验证双线性公式、分组和梯度，不接触额外人员。

原外查询20人、CoSpine13及新队列新评分0；新增MRI/ROI/FC、临床标签、QC改判、外部权重和其他训练均0。原79人和所有参照已反复开发，验证参与选轮，不能称独立验证。与旧16参数先验适配不同，本轮直接改变FC编码，检验网络对分块；不将原BrainHGT已保留的负边描述为本轮首次恢复。
