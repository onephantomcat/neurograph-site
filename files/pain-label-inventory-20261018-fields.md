# 可用疼痛字段与常见误读

| 来源 | 实际字段 | 单位与时点 | 不能替代的内容 |
|---|---|---|---|
| Emo临床工作簿 | 1_vas_pain_iv | 0–100，访谈当时 | 不等于任务中痛；16_mri_h只是MRI钟点；15_1/15_2是疲劳 |
| Emo任务论文/设计包 | 区块后当前疼痛；MAT names/onsets/durations | 论文0–10；包中VAS为条件名称和时间 | 不是实际VAS回答；情绪效价/唤醒不能代疼痛 |
| 音乐参与者表 | pic1/pic2/pim1/pim2 | 17人四条件VRS0–10；与TaskName对应 | pi为实验前NRS，不能代3位缺失条件分；PU为不愉快度 |
| DEIPP响应 | time/rating_intensity | 本次侧车样例60Hz、StartTime10秒；当前痛连续记录 | daily VAS_D是当天痛，WA/WW为周平均/最重；不能混为逐帧标签 |
| CoSpine事件 | PR／UpR | 0–10；分别疼痛强度/不愉快，刺激后报告 | pain/rating事件与PR/UpR不同；试次不是独立人 |
| DS005713新XLSX | Pain_severity (average score) | 平均痛0–10，98数值 | 电话随访NRS92、术后改善102不能当扫描同期痛；无精确评分日期 |
| SRPBS sup7/sup8 | VAS | 29／15人，端点和回顾窗待核 | 不能按最大值100或8推断量程并合并 |
| OA | Response、VAS/WOMAC改善百分比 | 治疗后结局 | 不能代基线疼痛或HC疼痛值 |
| PRT | pain_avg尚缺；Rating已有 | 临床周均痛与任务不愉快分别解释 | 不能把Rating/ROI任务强度当临床背痛 |
| 偏头痛任务 | onset/duration/trial_type | warm/pain刺激事件 | 没有数值受试者评分列，条件不等于主观痛 |

“未取得”限定在本轮已查的公开及持有材料，不证明作者没有采集或没有其他私有文件。没有为健康者补0、以未来值补当前，或将原日期/缺失改写。
