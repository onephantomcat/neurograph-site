# 小样本疼痛分级：诊断后的一轮论文方法改进

2026-10-18。用户要求分析小样本过拟合、等级不均衡和影像增量，再制定并执行一轮有针对性的改进，可用相关论文而非继续自建模型。本轮新患者上下文开始前写定；此前只复核150个旧模型、检索论文及准备运行环境/合成检查。

## 已有诊断与假设

原27位Emo纤维肌痛女性、访谈VAS0–100、三外折18训练/9测试与35/65研究分箱保持。全部60个影像有序模型（4家族×3折×5seed）训练等级误差0、训练宏F1=1；折级留出平均宏F1约0.244/0.298/0.333/0.252，等级误差0.719/0.630/0.622/0.859。四连续影像模型训练VAS MAE约1.08–1.62，留出约14.65–17.11。训练/留出差距强烈支持参数拟合过度，但不是唯一因果解释，也不证明所有影像方法无效。

5/16/6等级，原训练各折[4,11,3]/[2,11,5]/[4,10,4]；原查询[1,5,3]/[3,5,1]/[1,6,2]。少数类最少2训练人；总变差约.167/.222/.111。全部预测中等级可得59.26%准确率、宏F1.248、平均召回1/3、高召回0；但原Transformer过度报极端等级，不能把全部问题归为只报多数类。9/27距任一切点≤5VAS点，只提示分箱敏感，不能断言9个标签错误。各旧影像连续臂均未优于同优化器临床头；旧配对区间保留，缺可靠影像增量不能用换架构自动补齐。

本轮假设：用官方冻结表格先验替代18人从零训练，降低患者参数拟合自由度；用论文固定后验调整检验多数先验影响；在相同方法和人级划分下比较临床、影像联合及打乱影像消融。没有保证能修复弱信号或访谈/MRI错位。

## 固定输入与预算

复用20261013-pain-prior-transfer的Emo三份最终训练侧切空间PC≤8特征、13临床/混杂和原人员索引。原切空间参考、Scaler和SVD均由各18训练人拟合，逐项读回/独立数组验证；新增参考、SVD、传统模型拟合0，不用查询拟合表示或标签选PC维数。

四输入：clinical（13列）；pc_cov（8FC主成分+原4混杂=12列）；pc_clinical（8FC主成分+13临床=21列）；pc_clinical_shuffled（同21列，仅将训练侧8PC按事先seed确定的一次人排列打乱，保留本行临床/真实等级，查询PC不变）。打乱为训练侧影像关系消融，不是新的临床标签，也不作多次置换显著性检验。每外折/seed的打乱固定，无重复挑排列。

4输入×3原外折×5seed0..4=60主上下文；每个官方n_estimators=4、float32、CPU2、fit_with_cache、n_jobs1、softmax_temperature .9、average_before_softmax False。所有参数requires_grad=False，患者优化步骤0。每个查询独立调用，无其他查询特征/预测用于自身调整，查询标签只用于最终离线评价。完整60上下文另从同权重/训练数组重建并回放，不把回放算新训练；共540查询概率/原始上下文，回放另540。

三种固定后验：raw p；官方balance_probabilities的normalize(p/π_train)作完全先验平衡参照；DistPFN_single的normalize(p²/π_train)为主要改进。π仅训练人数，三类在每折训练均存在；不按全27人比例或查询标签修正。不得把平衡或DistPFN输出默认称原临床人群已校准风险，RPS/NLL亦报告。推理时实现与公式独立对照，概率不得出现负值或非有限值。

两种固定解码：argmax分类为主要macroF1/平均召回评价；累计概率≥.5数量的有序中位数为辅助等级误差评价。所有3后验×2解码×4输入=24组全部报告，不根据外折选择解码、后验或输入。M5先逐外折/seed完成调整再等权平均五组概率，保留每seed；原始概率集成与先调整后的集成不混用。

主要预定对比：pc_clinical / DistPFN_single / argmax相对同输入raw（调整因素）；相对clinical / DistPFN_single / argmax（影像增量）；相对pc_clinical_shuffled / DistPFN_single / argmax（影像标签关系消融）。其余所有方法为完整敏感性比较，不能挑最好表格行作为确认性发现。原MLP/GCN/CNN/Transformer与SPD全部旧结果及失败/停止保留。
