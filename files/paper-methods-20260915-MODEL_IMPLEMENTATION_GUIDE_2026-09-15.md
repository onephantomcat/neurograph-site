# 原切空间与论文方法：实现说明

日期：2026-09-15。以下描述本项目实际运行代码；论文原意与本地适配分别说明。

## 共同输入与评估

既有99人（Pain 46/HC 53），96人敏感性队列与其重叠。AAL90输入为每人240×90时序，TR=2.5秒；BrainLM改用真实A424。FC是功能连接，EC在本实验仅指滞后统计依赖图。

内部评估为按人5次重复×5折外层×3折内层。双向站点留出中，OSU→CIN测试50人，CIN→OSU测试46人；5次来源内层种子不增加独立人数。超参数、轮数、阈值只由训练侧选择。已反复用于开发的站点不是新中心临床验证。

第一轮神经候选使用 AdamW（lr=0.001）、类别加权 BCE、dropout=0.3、梯度裁剪1；内层选择20/60轮及权重衰减0.01/0.1。STAGIN训练设置见专节。

概率阈值默认0.5；另一分支在训练侧OOF概率的0.1—0.9网格（步长0.005）上最大化两类召回率的较小值，再按BA与接近0.5处理并列。阈值会改变召回率，不会提高AUC。

## 1. 原切空间 Logistic

240 × 90 脑区时序 → 收缩协方差 → 训练组参考 → 切空间 → 4005 维 → Logistic

把每个人的脑区共同波动，相对于训练组的共同参考，表示成一组可供线性分类器使用的偏差。切空间负责表示，Logistic 负责学习 Pain/HC 分类。

每人每 ROI 按时间均值和样本标准差标准化。Nilearn ConnectivityMeasure 使用 Ledoit–Wolf 收缩协方差；只用训练人群拟合几何均值 R，计算 log(R⁻¹ᐟ² C R⁻¹ᐟ²)。去对角线取下三角，90×89/2=4005 维；再用训练侧 StandardScaler 和 balanced L2 Logistic。C∈{0.001,0.01,0.1,1}，内层3折选参。

**适配与限制：** 矩阵对数作用于特征值，不是逐元素取 log，也不等同于相关系数 Fisher-z。参考、缩放与分类器均在各训练折重拟合；测试人只做 transform/predict。预处理主要是信号处理，分类器属于监督机器学习。

[论文或作者文档](https://nilearn.github.io/stable/modules/generated/nilearn.connectome.ConnectivityMeasure.html)

## 2. 静态 signed GCN

全程 Pearson FC → 正/负两路邻接 → 两层图传播 → 脑区读出 → 分类

把脑区看成节点、连接看成边，沿正连接和负连接分别收集邻居信息。

90×90 FC 的每行先映射为16维节点特征，并加入可训练脑区身份。正、负边分别作对称度归一化；每层包含自身、正邻居和负邻居三路线性变换，再做 LayerNorm/GELU。两层后按脑区顺序展平，经32维读出和分类头输出概率。

**适配与限制：** 这是本项目明确实现的轻量图网络，未使用 BrainGNN 的完整 ROI 选择结构，不能称为 BrainGNN 原版复现。

## 3. 纯时序 TCN

90 条 ROI 时序 → 两层时间卷积 → 均值/标准差池化 → 脑区读出 → 分类

直接学习信号在时间上的局部变化，而不是先把整个扫描压成一张连接矩阵。

各 ROI 共享 Conv1d：1→8 通道，卷积核7；第二层8→8通道、膨胀率2。时间维均值与标准差拼接后映射为16维，再加脑区身份，经读出层分类。

**适配与限制：** 这一支没有连接图传播；池化会压缩时间细节。它与图分支的区别可以用作时序信息的对照。

## 4. 时序＋FC GCN

TCN 时间特征 ＋ FC 行特征 → 节点级拼接 → 两层 signed GCN → 分类

先给每个脑区同时提供“信号怎样变化”和“与谁相关”，再沿连接图整合。

将每 ROI 的16维 TCN 特征与16维 FC 投影拼成32维，线性融合回16维，加入身份后使用相同的两层 signed GCN 与32维读出。

**适配与限制：** 这里 FC 指功能连接（functional connectivity）；“全连接层”另称 Dense/Linear。该融合在节点层完成，不是两个最终概率简单平均。

## 5. 动态 GCN＋GRU

7 个滑动窗口 → 每窗 FC → GCN → 窗口序列 → GRU → 时间平均 → 分类

把一张静态脑图改成按时间排列的脑图序列，学习连接怎样变化。

窗口60 TR=150秒，步长30 TR=75秒，共7窗。每窗90×90 Pearson FC 经两层 signed GCN 和32维读出，再送入隐藏16维的 GRU，对窗口输出取均值后分类。

**适配与限制：** 窗口是同一个人的重复片段，不是新增样本。所有窗口随人划分，不能把同一人的窗口分进训练与测试两侧。

## 6. 动态统计与切空间融合

7 窗 × 4005 条边 → 每边窗口均值＋标准差 → 8010 维（可加切空间） → Logistic

用每条连接的平均强度和波动程度描述动态性，减少对复杂神经网络的依赖。

dynamic_stats：4005条边的窗口均值与样本标准差合为8010维。tangent_dynamic：再拼接4005维切空间，合计12015维。两者都用训练侧 StandardScaler＋balanced Logistic，内层3折选择同一组 C。

**适配与限制：** 保留分布概况，但不保留窗口的先后顺序。动态统计也是手工统计表示＋监督机器学习。

## 7. DCSTN 高斯 TE 适配

动态 FC ＋ 定向依赖 EC → 两路空间图传播 → EC 引导时间注意力 → 窗口平均 → 分类

FC 描述同步变化；EC 分支用滞后统计依赖补充方向，再让它参与窗口注意力的计算。论文正确缩写为 DCSTN。

7窗形成6个相邻过渡：高斯一阶条件互信息 I(Y[t+31]; X[t] | Y[t+30])，相关正则0.001；每对脑区仅保留较大方向并加自环。前6窗 FC 与6个 EC 对齐；两层64维图传播、节点均值读出。FC＋位置编码生成 Q/V，EC 生成 K，经注意力、残差及时间均值分类。FC-only 对照以 FC 表示代替 EC。

**适配与限制：** 源到未来相隔31 TR=77.5秒，不是普通相邻1 TR神经因果。高斯单历史估计器、窗口、输入特征和训练预算均为适配；未确认原文高阶非线性估计器。EC 不能据此解释为已证实的神经因果。

[论文或作者文档](https://doi.org/10.1016/j.knosys.2024.112856)

## 8. STAGIN 作者模型适配

19 窗动态 FC → 身份＋GRU 时间编码 → GIN → SERO 注意力读出 → 时间 Transformer → 分类

同时学习每张脑图中哪些节点重要，以及哪些时间窗口更有分类价值。

采用作者模型源码 cedb566，仅缓存邻接矩阵。50 TR=125秒窗口、10 TR=25秒步长；按作者端点规则共19窗，末10帧不参与。按作者百分位规则保留前30%连接构图。比较128维×4层和32维×2层，单头注意力；内层3折选择15/30轮及容量。交叉熵＋1e-5正交正则，dropout 0.5，Adam 初始0.0005，OneCycle 峰值0.001、30步。

**适配与限制：** 使用全训练折 batch，区别于作者 batch=3，优化步数预算没有完整复现。主表容量选择行复用内层所选模型预测，不额外训练。保存模型重放判定一致，但24次完全匹配调用顺序的内层重训仍有10个模型-样本判定变化；只能视为探索性运行。

[论文或作者文档](https://github.com/egyptdj/stagin)

## 9. 冻结 BrainLM 与随机编码器

真实 A424 时序 → 3 段200帧 → 冻结编码器 → 3 个 CLS 均值：512维 → 训练 Logistic

借用预训练模型提取时序表示，只训练一个轻量分类头；同结构随机编码器检查收益是否来自预训练。

从清洗后4D BOLD 提取真实240×424时序。A424标签按物理坐标最近邻重采样到3mm BOLD；逐人逐ROI z-score，固定起点0/20/40三段200帧。使用 old_13M：4层4头、512维、13,429,292参数全部冻结，20帧一个 patch，4240个 token＋CLS；固定共同 token 排列，eval 模式。三段 CLS 取均值，StandardScaler＋balanced Logistic。随机对照同结构同输入，只换成一次随机初始化。

**适配与限制：** 数值就绪99/99不等于人工阅片通过：部分ROI仅1—3体素。当前公开检查点实际512维，与 FMM_TC 文中256维有差异；仅测试一种归一化与一个随机初始化，阴性结果不等于所有 BrainLM 方案无效。

[论文或作者文档](https://huggingface.co/vandijklab/brainlm/tree/main/old_13M)

## 10. 切空间 FC＋BrainLM 线性融合

4005 维切空间 → 拼接512维时序表示 → 4517 维训练侧缩放 → Logistic

让连接结构与时序表示互补，检查基础模型能否给原切空间提供额外信息。

参考疼痛药物反应研究 FMM_TC 的时序＋FC思路。当前将4005维切空间与512维冻结 BrainLM 特征直接拼接，训练同一组正则化 Logistic；tangent_random 使用随机冻结特征作对照。切空间参考与所有特征缩放都在训练侧拟合。

**适配与限制：** 未训练论文的 ResNet18 FC 分支，因此是“冻结特征线性融合适配”，不是整篇 FMM_TC 复现。论文任务是药物反应预测，本项目是异质 Pain/HC 分类，结局定义不同，不能直接对比分数。

[论文或作者文档](https://github.com/Shef-AIRE/FMM_TC)

## 结果怎样解读

本轮360个最终模型（STAGIN 120＋冻结特征分类器240）与第一轮480个最终模型分别统计；原切空间复用同划分存档预测，容量/阈值选择分支不计新增模型。没有稳定整体增益，保留原切空间开发参照。

STAGIN训练AUC接近1而留出AUC接近随机，存在过拟合；严格重训仍不稳定。冻结线性模型的240个最终模型独立回算通过。A424的99人数值就绪不代表新增视觉批准或临床训练纳入。
