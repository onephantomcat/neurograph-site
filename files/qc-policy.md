# SRPBS1600 FC-only QC 调整（2026-09-03）

研究者本轮明确要求“把时长QC移除，移除所有非必要QC”。本次策略名为 `srpbs_fc_essential_v2_no_min_duration`，仅用于新的 SRPBS `pilot-v4` 及后续同策略运行；DS005713 历史策略、结果与入组标准不变。

## 不再阻断计算的项目

- 取消可用时长至少5分钟的排除。继续报告扫描总时长、扣除高头动影响后的可用时长及旧5分钟参照标记；该标记不决定PASS/FAIL。
- 取消AAL提取器原先的20帧经验下限，只保留计算相关所需的至少2帧；时点数、有限性和有效回归仍受必要检查约束。
- 辅助的体素级平均FD图不再必须存在或全部有限。头动参数和Power FD仍必须有效，因为它们用于混杂回归与头动检查。
- QC图渲染或附加overlay复制失败只写警告，不阻断数值处理；人工视觉状态仍为待审，不会因此自动变成人工通过。
- 完成日志只要求至少有一次完成标记，不因重复标记失败；真实fatal错误仍阻断。
- 不再以掩膜外背景非有限值判定native BOLD失败；所用脑掩膜内仍必须有限。
- Stage 2不再要求未实际使用的MNI模板文件。平滑、ALFF/fALFF、ReHo/DC等未启用产物仍不要求生成。

## 保留的必要检查

- 输入文件、连续序号、体积数、TR、空间网格和来源一致；不覆盖已有输出。
- 真实计算完成且没有致命错误。
- 头动平移<3 mm、旋转<3°、扩展高FD帧比例≤20%，混杂回归矩阵有限且满列秩。
- 配准后的脑掩膜非空、必要WM/CSF支持存在；既有脑掩膜Dice>0.75及参考掩膜覆盖>0.90仍用于识别严重空间失败。
- 目标BOLD在分析掩膜内有限，滤波实际执行，图像时点数和TR正确。
- AAL标签及顺序1–90正确；参考脑掩膜口径每ROI有限覆盖≥0.92；FC/Fisher-z有限、对称，Fisher-z对角为0。
