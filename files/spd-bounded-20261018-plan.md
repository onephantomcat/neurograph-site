# 保持对角、尺度有界的SPD非线性：计算前方案

2026-10-18。接续已停止的中位尺度三次残差，不改写原7/250尺度超界结果。本轮基于本地三BiMap SPDNet（90→48→24→16，5997参数），只替换前两层激活；BrainHGT不变。当前轻量单BiMap90→16、1581参数作为已保存参照，旧三层ReEig200步另作同结构参照。

唯一候选：对中间SPD矩阵A，D=diag(A)，R=D^(-1/2)AD^(-1/2)，G(A)=D^(1/2)[(R+0.25 R⊙R⊙R)/1.25]D^(1/2)。0.25固定、不搜索；每个人矩阵自身对角参与可微运算，不拟合额外组尺度、不用查询人员设定参数。实现使用等价G(A)=A*(1+0.25 A²/(diag(A)diag(A)^T))/1.25；不detach对角、不人为覆盖对角以掩盖误差。正系数Schur乘积保持正定；对角不变、符号不变；|Rij|≤1下每元素相对变化≤20%，Frobenius相对变化亦≤20%。这些是数学性质，仍需真实数值验证，不保证性能。
