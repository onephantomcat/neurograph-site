# K10/20同类跨站点偏移与总体幅度检查：计算前方案

2026-10-17，先记录诊断和有限条件模型，再读取新结果。原上一轮站点组平衡候选未启动的结论不变；本轮检查影像条件分布，是另一个问题。

沿用原99人、5外折、每折5支持重复、K10/20共50支持面板及seed0..4。每面板只读取其支持人影像、标签、站点和原支持侧参考。外层查询不参与参考、尺度、对齐或决定。原99人已用于开发，不能把此次诊断或后续外层评价称独立验证。MRI、FC和权重留在服务器；CPU两线程，不改GPU或他人进程。

1. 对每支持面板的每一站点对，仅当两站点的两类别均至少2人时计算同类均值差，其余保留计数不足原因。三种表示：90维SPD的矩阵对数（对称向量化）；去全局log行列式幅度后的完整形状；原训练模型136维投影对数及减去全局幅度乘单位阵的投影形状。另列标量a=logdet(H C H)/90。总体幅度不是第五协变量。
2. 每个类别内999次按人置换站点，保持两站人数和类别数，随机种子由面板和站点对确定。以观测两站同类质心平方距离／置换均值比较有限人数造成的距离；报告置换尾比例与病例/对照偏移方向余弦，后者不把正方向预设为事实。所有seed和支持重复保留，面板重叠，不合并为独立统计检验。完整90维表示作为非学习参照，决定只使用原模型的去总体幅度投影形状。
3. 复用上一轮93站点块×两种内部划分×5seed=930权重与186个各自内训练参考。对其原留出支持人作固定模型敏感性分析：原预测、将总体幅度置为该内训练均值的预测、只保留总体幅度变化的影像分量加原协变量预测。不拟合新头，不以测试标签调整幅度方向或阈值。保留四协变量。严格区分固定权重干预与重新训练，也不能据AUC变化称幅度是采集混杂或疼痛因果信号。
4. 对logit作精确分解：a变化项系数为136维头中16个对角权重之和／原特征RMS。用原模型在显式缩放矩阵上的谱前向核对；若谱截断使等式不成立，保留失败并停止该数学分解，不悄改阈值。只幅度分量的截距取内训练平均形状分量；不使用留出标签。原预测逐项对齐旧保存预测。
5. 内层AUC汇总复用上一轮面板、外折等权和共同2000次人员条件抽样，seed0..4均值与M5分开。K10有效共同抽样不足100不报区间，不能临时换方法追求显著。不公开稀疏站点的个人分数；公开预算×表示×seed×重复的汇总及资格原因。

是否开展唯一条件对齐候选，按计算前明确的训练内依据判断，四项须全部满足：两预算至少20/25支持面板可比较；去幅度投影形状的质心距离／置换均值在两预算均≥1.25且至少4/5支持重复>1；两类别偏移方向平均余弦在两预算均≥0.25且至少4/5重复>0；固定权重去幅度后留站点M5 AUC在两预算均≥0.55、随机减站点差均≥0.02且至少4/5重复>0。阈值是本次有限推进约定，不能当通用有效性界线。任何项不足则记录未启动，不把未运行写成模型失败成绩，不再扩参数空间。

若满足，只训练一个类别条件均值对齐SPD：原类平衡BCE + 0.1×同类跨站点136维特征均值平方差的维均值，类别/可用站点对等权，每组至少2人；用原固定支持特征尺度，保留全部支持人和原四协变量。损失中的形状特征为原投影log减aI，不剥除预测头的幅度。W、头、参考、初始化、200步SGD0.01/正QR/头L2 0.001均沿用原设置，部署参数不变。5折×5重复×K10/20×5seed=250模型；K20为主，K10次要，与原同人同预算比较，所有指标/seed/阴性/权重保留，不选λ或最佳seed。无可对齐组时该项为0并明确计数。

条件对齐文献只作方法背景：[Jiang等，ICML2020](https://proceedings.mlr.press/v119/jiang20d.html)。这里使用已知支持标签和固定均值罚项，不运行其无监督域对抗采样方法，不声称论文复现或数学首创。
