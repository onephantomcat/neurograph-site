# 协方差几何体积、ROI方差、头动与处理流程：诊断前方案

2026-10-17启动。首次只读核查发现，当前99×240×90输入时序各ROI样本方差与1误差≤2.45e-15。旧SPD步骤未再标准化，不等于上游未标准化。本轮先追溯原ROI时序和标准化记录，更正“幅度”的解释；不修改旧模型、AUC或失败结果。

沿用原5外折×5支持重复×K10/20共50面板。只用每面板支持人员计算关系、残差、阈值和训练决定，外层查询不参与。所有原seed0..4/重复/阴性保留，诊断置换也分别记录seed0..4。不新增QC、临床标签、全局参考或强线性模型搜索。服务器CPU2，矩阵/原ROI时序/权重留服务器，只有必要私有统计读回。

核查内容：

- 对当前99人的准确来源路径读取原90ROI时序和既有QC元数据，核对每人标准化后与当前输入逐项一致。缺失或不一致逐人私有保留，不换来源。量化原ROI平均/几何均值方差、当前ROI方差、当前Ledoit-Wolf协方差对角和迹。
- 用a=logdet(C)/90，v=mean(log diag C)，q=logdet(corr C)/90核对a=v+q。当前各ROI方差恒定时，a主要是相关谱的几何体积，不是原始BOLD强弱。另从当前时序重构经验协方差，推回收缩系数，独立重算C；分开记录相关结构和收缩的影响。乘2原时序再按人/ROI标准化检查输入不变；不把这一代数恒等式当去除所有采集差异。
- 各支持内计算a与原ROI方差、平均FD、censor、年龄、性别编码、收缩率及相关谱的Pearson/Spearman；另对站点/处理策略/批次的解释比例和残差关联作描述。常量变量相关标未定义，不把浮点噪声当可解释方差。
- 同站点病例/对照均至少2人才报告差异，原a、原ROI方差、收缩率分别计算均值差和SMD。另用当前支持内年龄/性别编码/FD/censor、站点、处理策略与实际批次作普通最小二乘残差诊断，不作临床因果调整；秩亏按实际秩处理，残差自由度不足5标不适用。站点与protocol共线时不能声称区分站点和采集协议效果。
- 在支持内按站点×处理策略×批次分层，999次置换病例标签，seed0..4分别保留。报告可实际交换人员/分层覆盖；没有可交换信息时不伪造p值。置换为描述性稳定性，不合并重叠支持或seed为独立人。
- 检查原QC的TR、体素/时间维度、过滤目录、protocol和预处理版本/修复来源。未记录扫描仪增益、强度归一化或早期参数就明确未知，不以目录名推断GSR/流程相同。

条件模型在诊断前限定：原始物理幅度分支只有实际输入保留ROI方差时才有定义；若标准化证实，则不按原始BOLD幅度解释训练。可以考虑的唯一候选改称“几何体积分支+投影形状分别正则化”，仅当以下支持内依据同时满足才运行：来源标准化和C代数核对通过；两预算全流程调整后标准化病例系数均≥0.20且至少4/5重复正向，并且两大站点原a的平均病例差均正向；两预算可比较同站点面板≥20/25，且至少80%支持面板在主要站点中存在同批次同策略两类可交换人员；两预算调整站点/流程后的a与FD、censor绝对相关均≤0.50。数值仅为有限推进约定，不是通用有效阈值；不足就未启动，不调整条件追分。
